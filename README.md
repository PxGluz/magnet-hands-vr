# MagnetHandsVR

Project made for the Development of Virtual and Augmented Reality Systems course of the Graphics, Multimedia and Virtual Reality master program.

## Team members
- Popa Bogdan Gabriel
- Roșu Mihai Cosmin

## Details
Small VR game in which the player has to use magnetism with the help of his hands in order to traverse the levels and solve puzzles.

The player can use magnetism through each hand in order to pull/push objects or push/pull himself away from/towards an object. Using this he can advance through the level by jumping from wall to wall, climbing walls or jumping through the air. On the puzzle side, there are doors which need multiple buttons to be pressed in order to open.

## Technologies used
- Unity 2022.3.62f2
- SteamVR
